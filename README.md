# ai-teacher

基于教材、论文与学习目标进行辅导、检索练习和反馈，帮助学习者形成可检验的理解。

这是一个以中文编写的 Agent Skill，包含技能说明与配套参考文件，不包含模型、应用程序或课程原始材料。

## 使用

将完整仓库文件夹作为 `ai-teacher` 技能目录，交给支持 `SKILL.md` 的客户端加载。也可让 AI 先读取本仓库的 `SKILL.md`，再按入口链接读取需要的参考文件。具体安装位置由所用客户端决定，不能只复制入口文件而遗漏参考资料。

示例请求：

> 请用 $ai-teacher，基于我提供的教材第 2 节，帮助我理解核心概念。我会基本代数，请先给一个例子，再让我独立尝试，并针对我的回答反馈。

提供的材料、目标范围与语言要求优先；不需要为了使用技能先填完一套问卷。

可参考[模拟辅导示例](references/example-tutoring.md)，了解如何根据学习者的尝试调整反馈。

## 文件

- `SKILL.md`：技能入口与使用边界
- `references/`：按需读取的方法与来源参考
- `agents/openai.yaml`：技能显示信息

## 适用范围与限制

技能提供教学与笔记工作流程；AI 生成的解释、计算与反馈仍需核对。输出笔记、答对一道题或感到熟悉，都不能证明长期掌握。需要 PDF、图像、字幕或代码验证时，实际能力取决于运行环境中的工具。

来源说明保留了设计阶段的阅读范围与证据边界，发布时未重新验证所有外部材料，也未验证本技能的学习效果。书籍、论文、课程文件及第三方原始技能不随仓库分发，第三方内容的权利仍归原权利人。书目定位可能因版本而异，需要精确归因时重新核对原文。

## 材料与隐私

公开仓库只包含技能说明、方法参考和文本示例。用户输入的教材、课件、教师答案、字幕、作答、学习档案及生成的课程笔记，不因使用本技能而获得公开或重新许可的权利；请将这些资料存放在仓库之外。

本包没有额外的采集服务或上传脚本。所使用的 AI 客户端和工具可能向服务商发送输入，具体取决于其设置与条款，因此不承诺全部处理只在本地进行。提交问题或示例时，先去除个人资料并确认有权公开。
