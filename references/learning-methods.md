# 学习方法的选择与调整

整合设计阶段参考的四部著作，按学习卡点使用。下列规则是本 skill 的教学设计，不是逐字摘录；书籍位置与证据边界见 [来源映射](source-map.md)。常规辅导无需重新读取 EPUB。

## 先识别需要改善的表现

短问题直接教；长期项目才补充最终用途、可投入时间与检验方式。区分概念理解、事实记忆、操作技能，以及“何时选用某方法”的判断。先看一个实际尝试，避免仅根据学习者的偏好或自信诊断。

| 观察到的卡点 | 优先改动 | 检查什么 |
|---|---|---|
| 看着懂，合上材料说不出 | 闭卷检索，作答后核对与纠错 | 隔一段时间仍能解释关键条件 |
| 当天会，过几天忘 | 把集中复习拆成多次检索 | 延迟后的准确性与提示需求 |
| 按章节会做，混合题不知道用哪招 | 交错相关、易混淆的题型 | 能选方法并说明判别线索 |
| 能背定义，不能解释或应用 | 自我解释、具体例子、反例与条件变化 | 能解释为什么成立及何时失效 |
| 会单项，真实任务做不成 | 完整任务 → 弱项训练 → 回到完整任务 | 专项改善能否整合到目标表现 |
| 难以启动或反复分心 | 一个可开始的动作，短专注时段与预定休息 | 实际开始、完成及学习表现 |
| 认真尝试仍困在同一路径 | 记录卡点，短暂离开，回来换表征或检验假设 | 是否产生可验证的新解法 |

## 记住与辨别：检索、间隔、交错

**检索**：离开材料后复述、推导、解题或实际操作；选择形式要匹配目标，不能只把阅读换成选择题。新内容可先预测或尝试，再看解释，但不要让学习者长期猜测未知事实。作答后核对正确答案、条件和错误原因；AI 提供的答案同样需要材料或可验证推理支撑。需要时给最小提示，再逐步撤除。互动题目不要紧接着泄露答案；教师索取答案册时正常提供。

**间隔**：在已有时间预算内把一次长复习拆开，每次先回忆、再补漏。回忆稳定可延长间隔；经常失败或完全无法检索时缩短间隔并重建理解。安排取决于目标保留期、截止时间和表现，不把固定日程当成普遍最优。临时应试可以压缩计划，但应说明当天成绩无法证明长期保留，不因此拒绝帮助。计划不自动创建提醒。

**交错**：先让初学者理解必要概念和基本操作，再混合相关题型，训练“这题为什么用这个方法”。不要提前标出题型或固定顺序，让学习者仅凭位置套公式。交错、间隔和变式是不同维度：交错训练方法辨别，间隔改变复习时间，变式改变情境或表面特征。不要把无关任务切换或同时分心包装成交错学习。

## 理解与技能：生成、连接、直接练习

让学习者解释步骤原因、连接旧知识、提出例子或反例；解释顺畅后仍需要独立解题或迁移检验。记忆术、图像、类比与记忆宫殿可辅助任意事实的记忆，但不能替代理解、推导或操作；说明类比对应关系与边界。

技能项目优先使用最终任务或保留其关键约束的模拟。例如学编程要写并运行程序，练口语要真实表达，学论证要构造并检查论证。AI 可示范、给反馈和模拟情境，但不能代做后把作品记作学习者的成果。

用完整尝试识别瓶颈：哪个子技能拖累整体，或因同时处理太多要素而练不到？隔离该弱项练习，再回到完整任务检查。专项进步没有带来整体改善时，重新诊断或改练法，而非继续堆重复量。直接练习也不保证自动迁移，仍需在新情境检验。

## 专注、休息与学习负担

拖延时把“学完一章”改成一个可开始的过程目标，例如读一段并闭卷解释。计时专注与短休息可作起点，时长按年龄、精力、任务和反馈调整，不规定人人必须 25 分钟。复杂推理时减少干扰；认真尝试后卡住，可记录已试路径与未解决点，短暂休息后返回。休息孵化不等于边学边刷消息，也不保证灵感出现。

可在不妨碍专注时改变练习情境、表征或地点，以检查是否依赖单一线索；不强制去咖啡馆、播放音乐或放弃稳定学习环境。睡眠作为可持续学习安排的约束，不根据书中的睡眠阶段故事安排熬夜，也不在此提供个体医疗判断。

“专注／发散模式”“注意力章鱼”“脑连接”等是帮助理解的教学模型或比喻，不能用来诊断个体脑状态，或把每一步练习直接等同于某种神经变化。

## 自主项目与方法实验

参考 Ultralearning 的九原则选择当前需要的部分，不把它们变成固定九步：

- **元学习**：从用途画出概念、事实、操作技能和先备知识的简图，选资源及可检验的任务；避免规划长期替代练习。
- **专注、直接性、专项训练**：服务目标任务，按实际瓶颈调整。
- **检索、反馈、保留**：先做再核对，并在后续重试。反馈区分结果是否成功、哪里出错、如何修正；有依据时给出修正路径，而非只有分数或赞美。
- **直觉**：通过解释、推导、例子与反例深化结构理解；记熟公式不足以证明理解。
- **实验**：比较资源、练习方法或任务挑战，按观察调整；作者案例不意味着必须高强度、全职或复制其时间安排。

改进方法时，先记录当前表现，每次尽量改变一个主要因素，用难度相近的任务比较延迟回忆或实际应用，同时考虑耗时和负担。个人试验用于决策，不冒充因果研究。可把作答前的信心与实际表现对照，帮助识别熟悉感造成的误判，不把自信当成绩。

尊重学习者偏好与无障碍需要，但不据此贴固定的“视觉型／听觉型”标签或限制学习方式。鼓励具体策略、改错与进步，不宣称努力、成长心态或某个方法能保证成功。持续失败时补先备知识、示范或减负；有益难度需要可达目标与纠错机会，不能用“越痛苦越有效”合理化无效练习。
