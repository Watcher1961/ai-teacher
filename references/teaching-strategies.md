# 教师教学策略

先明确对象、学习目标、已有知识和课时；已提供的信息不再询问。只选能服务目标的策略。不要把“学过某个先备知识”推定为已经学习目标概念或符号；未知时用简短说明降低入口负担，或将实际影响测验用途的假设明确为待教师确认。

| 卡点 | 可用策略 | 核验重点 |
|---|---|---|
| 只认得一种例子 | 多样例子：变化背景，保留共同原理，并加入边界或反例 | 例子真能体现该概念，变化不只换名字 |
| 一个解释听不懂 | 更换表述、具体例子或类比 | 事实一致，类比的对应及失效处明确 |
| 看似懂但记不住 | 低风险检索测验 | 目标对齐、题意明确、答案与评分规则正确 |
| 不知道哪里没懂 | 最重要概念／最困惑处短反馈 | 从原始回答定位主题，区分观察与推测 |
| 会新内容却忘了旧内容 | 分布式检索与新旧概念连接 | 延迟后仍能回忆，时间与难度适合课程 |
| 同类题会做，混合题选错方法 | 相关题型交错练习，让学生先判断再求解 | 学生已有必要基础，题干未直接泄露解法 |
| 单项技能会，完整任务失败 | 完整任务诊断、弱项专项练习、再整合 | 改善能回到目标任务，未只提升专项成绩 |

## 生成材料

教师用练习可同时交付题目、独立答案和评分依据，便于审阅；将学生页与教师答案分开。检查歧义、单位、假设、解答步骤和目标对齐。互动学习的“不先给答案”不妨碍教师索取完整答案。

概念题可要求解释为什么、辨别反例或迁移；选择题干扰项应对应可能的误解。难度应来自目标概念，不来自无关阅读负担。材料作为教师可审阅草案，不声称已在课堂验证。

## 分析学习反馈

对给定回答归纳主题并给出代表性证据，指出需要补教的概念；保留不符合多数模式的意见，避免硬凑固定三个主题。缺少足够信息时标注不确定，不推断学生的智力、动机或身份。

建议的下一课活动应回应具体困惑，并用简短检索再次检查。需要课堂之外实际上传、发送或安排活动时，遵循用户授权；分析材料不隐含发布学生信息的许可。

需要设计间隔、交错、生成式练习或自主项目时，读 [学习方法的选择与调整](learning-methods.md)。基础不足时先示范并补前提，再逐步撤除支架；不为了制造困难增加无关阅读负担。反馈优先指出具体步骤与修正方法，而非只给分或评价能力。
